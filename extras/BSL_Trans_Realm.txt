# Trans Realm preset for BSL Shaders (Iris or OptiFine)
#
# How to use:
#   1. Put this file in .minecraft/shaderpacks/, next to your BSL zip.
#   2. Rename it to the zip's exact file name plus ".txt",
#      e.g. BSL_v10.0.zip -> BSL_v10.0.zip.txt
#   3. Pick BSL under Video Settings > Shader Packs.
#
# The look: pink sunrises and sunsets, soft pink-white daylight, lavender nights, sky-blue skies and water,
# pink lamplight, a little extra bloom and colour. BSL's own clouds are turned off so the mod's heart clouds
# (which cycle blue, pink, white, pink, blue) stay visible. Lighting strengths are left at BSL's defaults.
# Shader settings apply in every dimension, so the Overworld gets the pastel tint too.
# Options this BSL version doesn't know are skipped, and changing anything in the shader menu rewrites this file.
