# Trans Realm preset for BSL Shaders (Iris or OptiFine)
#
# How to use:
#   1. Put this file in .minecraft/shaderpacks/, next to your BSL zip.
#   2. Rename it to the zip's exact file name plus ".txt",
#      e.g. BSL_v10.0.zip -> BSL_v10.0.zip.txt
#   3. Pick BSL under Video Settings > Shader Packs.
#
# What it does:
#   - Clouds: BSL's own clouds are off, so the realm's heart clouds show, cycling through the flag
#     (blue, pink, white, pink, blue). If you see no clouds at all, open BSL's settings, find Clouds
#     under Atmosphere and pick the vanilla option.
#   - Sky and fog follow the game's own sky colours, so the Trans Realm keeps its trans-blue sky, pink fog and
#     pink-and-blue sunsets while the Overworld stays normal.
#   - Water takes each biome's colour: blue seas, pink rivers, lavender crystal pools.
#   - Pink sunrises and sunsets, pink-white daylight, lavender nights, lilac shadows, pink torchlight.
#   - Brighter colours, a soft pink colour grade, extra bloom and glow.
#
# Lighting strengths stay at BSL's defaults. Options your BSL version doesn't have are skipped, and changing
# anything in the shader menu rewrites this file.
